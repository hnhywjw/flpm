# ProjectFlow

**Full Lifecycle Project Management** ｜ 项目全流程管理 ｜ 招投标到回款

覆盖 **招标 → 投标 → 中标 → 合同 → 实施 → 验收 → 开票 → 回款 → 保证金返还 → 质保金 → 售后** 全流程，
责任到人、双时间轴（计划/实际）、金额四本账（应收/应付/保证金/过单费）。

| 项目 | 版本 |
|---|---|

| npm | 随 Node.js 安装 |

## 启动步骤

```bash
# 1. 进入目录
cd projectflow

# 2. 安装依赖（首次，约 1-3 分钟）
npm install

# 3. 初始化数据库（建表 + 灌入演示数据）

npm run dev
```

浏览器打开 http://localhost:3000

## 已实现的功能

### 核心流程
- **11 节点链**，含并行节点「投标保证金返还」（不阻塞主线）
- 每个节点：责任人、计划时间、实际时间、自动偏差天数、备注
- 节点推进有守门：**验收四件套未齐备（4/4）不允许推进到「开票」**

### 直接中标 / 代中标 双模式
- 项目级 `mode` 字段区分，详情页按类型自动显示「代中标」页签
- **过单费两种结算方式**：
  - **差价法**：`客户合同额 − 中标公司开票额 = 过单费`，差额留存
  - **现金方式**：`客户合同额 × 费率 = 过单费`，按 100% 开票
- **个人收款强制三件套**：代中标协议、付款凭证、收款确认单，缺一不可（服务端校验）

### 合同与回款
- 客户合同 **1:N**（一个项目可有多份：主合同 + 补充协议）
- 采购合同独立台账（成本侧）
- 付款比例结构化录入 → **自动生成回款计划**（末期用减法兜底，保证合计等于合同额）
- 开票方式：全额一次性 / 按付款比例，与回款计划联动
- 逾期天数自动计算，账龄分析

### 投标合规
- 参与方留痕：公司名、报价、关联关系标注、核查人、核查时间
- 关联风险红色标注 + 预警提示
- ⚠️ 系统**只做记录与风险提示**，不提供报价协调、陪标编排等功能

### 其他
- 出入库与项目/工单强绑定，设备 SN 台账
- 售后工单 SLA、质保期台账（质保到期 = 质保金可收）
- 8 类角色权限矩阵
- 6 套主题配色 × 深/浅侧栏，本地记忆

## 数据设计要点

1. **金额统一存「分」（INTEGER）**，避免浮点误差；界面按万元展示
2. **合同是收付款的法律依据**，回款计划挂在合同上而非项目上
3. 付款比例自动生成回款计划时，**末期用减法兜底**（`合同额 − 前几期之和`），
   保证四舍五入后合计仍等于合同额
4. 一个项目多份客户合同时，项目级金额取 **SUM(contracts.amount_cents)**
5. 过单费个人付款的三件套校验在 **API 层强制**，不依赖前端
